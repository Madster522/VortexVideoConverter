Vortex Video Converter v4.3
v4.3
Current

GitHub + website polish

Improved repository documentation, sharing metadata, keyboard focus visibility, reduced-motion support, and direct GitHub navigation without changing the converter workflow.

v4.2

Scene-aware motion engine

Added automatic scene/detail detection, motion smoothing for fast movement, and a live Vortex load meter that warns when settings may be laggy.

v4.0
Current

Website + branded end cards

New full website layout, navigation, changelog, credits, improved help text, versioning, and a required “Made with Vortex Video Converter” ending added to every export. The ending is generated as real pixel frames, so it works on the same Part screen as the video.

v3.2

Higher quality video engine

Added 24-bit color, gamma-correct supersampling, edge-preserving sharpening, temporal anti-flicker, and cleaner dark-scene handling.

v3.0

Auto Vortex

Automatic resolution and FPS selection based on video length, aspect ratio, and estimated Part-update workload. Added Fast, Recommended, Better, High, Ultra, and Custom modes.

v2.0

Smart compression

Added full-frame, run-length, delta-frame, and duplicate-frame compression so Vortex scripts can be much smaller while preserving timing.

v1.0

First release

Basic browser video sampling and Vortex Part-screen Lua export.
